Published R Packages

agentr and five supporting packages.

All six are on CRAN. Descriptions cover current development; GitHub may include features beyond the published release.

agentr

CRAN

My core package for agent design: editable workflow, memory, and knowledge specs, validators, prompt contracts, and visual review pages for coding assistants to implement approved designs.

CRAN Package GitHub

inferencer

CRAN

R and shell tools for hosted and local model APIs, including OpenAI, Gemini, Qwen, DeepSeek, and OpenAI-compatible servers, with fallback queries, embeddings, image generation, TTS, and multimodal input.

CRAN Package GitHub

okxr

CRAN

Typed OKX REST API wrappers for market data, accounts, trading, asset history, copy trading, and affiliate data, with shared signing, response parsing, and optional retries.

CRAN Package GitHub

binxr

CRAN

A Binance REST client for Spot, USD-M Futures, and Options, returning market data, account information, and order results as R tables.

CRAN Package GitHub

investdatar

CRAN

Retrieves and synchronizes macro, market, company, and positioning data from sources including FRED, SEC EDGAR, SDMX agencies, and crypto exchanges, with local storage and freshness checks.

CRAN Package GitHub

strategyr

CRAN

Turns market features and portfolio state into signals, target allocations, and order intents, with walk-forward strategy evaluation and backtests that track changing account state.
